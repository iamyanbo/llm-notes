# Neobrutalism design reference

The blue palette, 4px offset shadow, 5px corner radius, and button hover treatment in `public/neobrutalism.css` are adapted from Neobrutalism components by Samuel Breznjak:

- https://www.neobrutalism.dev/r/styling/blue.json
- https://www.neobrutalism.dev/r/button.json
- https://www.neobrutalism.dev/

The existing native HTML controls retain their implementation; the React component library is not installed.
